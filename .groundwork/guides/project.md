# Groundwork behaviour guide

Keep shared context and bounded journeys in `.groundwork/guides/` or subsystem maps, with configuration in auto-discovered `.groundwork/verify.d/*.json`. The small `.groundwork/VERIFY.md` bootstrap links to project context; use `groundwork view guide [query]` for discovery. New features need no central include list or root index update. Keep task, PR and run histories with their own records.
