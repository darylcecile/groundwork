### Final PR verification

The reusable workflow is `.github/workflows/verify.yml`; its runtime and prompt live in `pr-verification/`. It prepares metadata before loading configuration and capturing source, runs the importing project's selected checks, then uses the agent for remaining verification gaps, including unsatisfied review obligations, captures evidence, and updates the importing PR's verification comment. Valid exact-ID review evidence can satisfy a review obligation without another agent pass. It discovers the converted configuration fragments. Local evidence defaults to the external store; CI supplies runner-temporary output. The integration tests cover failures, missing evidence, source changes, nested project paths, and comment targeting and updating. A later agent pass cannot erase a failed check.
